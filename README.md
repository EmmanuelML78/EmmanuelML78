## Featured projects

### [Lead Intelligence Hub](https://github.com/EmmanuelML78/lead-intelligence)

Helps sales teams decide which leads to contact next and assign work within advisor capacity.
Combines data ingestion and deduplication, Gemini-based conversation extraction, explainable priority scoring,
and a dashboard. Built as a technical-assessment MVP with synthetic data; AI extracts facts rather than deciding the final score.

**Technologies:** TypeScript, Next.js, PostgreSQL, Prisma, Gemini, Python.

### [La Gambeta API](https://github.com/EmmanuelML78/la-gambeta-back)

Centralizes sports-venue and court management, availability, bookings, and payment checkout.
The modular API includes role-based access, overlapping-booking prevention, and payment-provider adapters.
The portfolio setup uses Polar Sandbox by default.

**Technologies:** TypeScript, NestJS, PostgreSQL, Drizzle ORM, Better Auth, Swagger/OpenAPI.

### [ACME Order Pipeline](https://github.com/EmmanuelML78/acme-order-pipeline)

Demonstrates an event-driven order workflow: validate inventory, publish events through Kafka, simulate payments,
and update order status. Uses PostgreSQL and MongoDB to support the processing flow, with Docker Compose for local setup.

**Technologies:** Python, FastAPI, Kafka, Protobuf, PostgreSQL, MongoDB, Docker Compose.

### [FinanceApp](https://github.com/EmmanuelML78/prueba-tecnica-fullstack)

Brings income and expense tracking, user management, and financial reporting into one full-stack application.
Includes GitHub sign-in, role-based access, reporting charts, CSV exports, and a documented REST API.
Built as a technical-assessment project.

**Technologies:** TypeScript, React, Next.js, Tailwind CSS, PostgreSQL, Prisma, Better Auth.
